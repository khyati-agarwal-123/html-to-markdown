## DBMS_HYBRID_VECTOR

The `DBMS_HYBRID_VECTOR` package contains a JSON-based query API `SEARCH`,
which lets you query against hybrid vector indexes.

  * [SEARCH](search.html)  
Use the `DBMS_HYBRID_VECTOR.SEARCH` PL/SQL function to run textual queries,
vector similarity queries, or hybrid queries against hybrid vector indexes.
